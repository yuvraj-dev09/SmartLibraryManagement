# 📚 Smart Library Management System

## 📌 Project Overview
Smart Library Management System is a C++ based application designed to manage library operations efficiently. It helps organize book records and issue records using different data structures and file handling techniques.

## 🚀 Features
- Manage book records.
- Search books using Book ID.
- Maintain student and book issue records.
- Save and load records using file handling.
- Efficient searching using Hashing.
- Store and manage data efficiently.

## 🛠️ Technologies Used
- C++
- VS Code
- Standard Template Library (STL)

## 🧠 Data Structures and Concepts Used
- **Vector:** To store and manage book and issue records.
- **Unordered Map:** For efficient searching using hashing.
- **File Handling:** To store and retrieve records from text files.
- **Structures:** To organize book and issue record data.

## 📂 Project Files
- `main.cpp` – Main program implementation.
- `library.h` – Library header file.

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Compile the C++ program using a C++ compiler.
4. Run the generated executable.
